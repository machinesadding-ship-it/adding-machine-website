ADDING MACHINE WEBSITE — MACHINE BRANDING REVISION

IMPORTANT:
This is a branding and UX text revision only.

Do NOT:
- change the $ADD token contract
- change tokenomics
- change wallet addresses
- change mint allocations
- change existing smart-contract logic
- invent APR, TVL, pool addresses, or reward data
- redesign the entire website
- copy branding, text, layout, icons, or assets from PancakeSwap or any other project

Keep the existing ADDING MACHINE visual identity:
dark industrial / vintage mechanical / machine-themed.

==================================================
1. AIRDROP REGISTRATION
==================================================

Replace:

AIRDROP REGISTRATION

With:

MACHINE REGISTRY

Subtitle:

Register your wallet for active airdrop campaigns.

Keep the actual registration functionality unchanged.

Registration action buttons should use simple familiar language such as:

REGISTER

Do not use complicated machine terminology for the action button.

==================================================
2. ELIGIBILITY CHECKER
==================================================

Replace:

ELIGIBILITY CHECKER

With:

MACHINE CHECK

Subtitle:

Check whether your wallet is eligible for the current campaign.

Keep the eligibility-checking functionality unchanged.

Main button:

CHECK ELIGIBILITY

Possible status messages:

ELIGIBLE
NOT ELIGIBLE
NOT REGISTERED
CHECKING...

==================================================
3. LP FARMING
==================================================

Replace:

LP FARMING

With:

MACHINE PRINT

Subtitle:

Stake your liquidity position and earn $ADD rewards.

Explain the feature in simple language.

Use this 3-step flow:

1. ADD LIQUIDITY
Provide assets to an approved ADD liquidity pair.

2. START MACHINE PRINT
Stake your LP or eligible liquidity position.

3. COLLECT $ADD
Claim rewards generated by your position.

Pool cards should remain easy to understand.

Example:

ADD / WETH

Liquidity Pair
Stake LP → Earn $ADD

APR: TBA
TVL: TBA
Status: COMING SOON

Do not display fake APR or TVL.

==================================================
4. CLAIM PAGE
==================================================

Replace the section/page title with:

OUTPUT CLAIM

Subtitle:

Claim available $ADD rewards.

IMPORTANT UX RULE:

The actual transaction button must remain:

CLAIM

Do NOT rename the CLAIM button to:
COLLECT OUTPUT
PRINT
OUTPUT
or any other branded terminology.

Other allowed button states:

CLAIM
CLAIM ALL
CONNECT WALLET
NOTHING TO CLAIM

Users should immediately understand what the transaction does.

==================================================

Any feature that does not yet have a verified live contract must remain:

or

TBA

Do not create placeholder/fake blockchain transactions.

Preserve the existing production website functionality outside these requested branding changes.
